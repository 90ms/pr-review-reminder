# macOS 수동 검증 체크리스트

자동 테스트가 확인할 수 없는 메뉴바 앱, 시스템 권한, 실제 CLI 연동을 릴리스 후보마다
깨끗한 macOS 14+ 계정에서 확인한다. 테스트 저장소와 PR만 사용하고 화면 자료에는
개인·회사 저장소명, 코드, 작성자, 토큰 사용량을 포함하지 않는다.

## 설치와 시작

- [ ] `brew install 90ms/tap/pr-review-reminder`가 source build를 완료한다.
- [ ] `pr-review-reminder --install-app` 후 앱이 메뉴바에 나타난다.
- [ ] `--doctor`와 설정의 의존성 진단 결과가 실제 `gh`/AI CLI 상태와 일치한다.
- [ ] **로그인 시 실행**을 켜고 로그아웃·로그인하면 앱이 한 번만 실행된다.
- [ ] Homebrew 업그레이드 후 Applications 링크와 설정의 현재 버전이 갱신된다.

## 핵심 흐름

- [ ] 수동 새로고침이 기존 목록을 유지하면서 성공·실패 상태를 구분한다.
- [ ] 예약 실행 후 설정에 성공/실패, 실행 시각, PR 수 또는 오류가 남는다.
- [ ] 네트워크 또는 인증 실패 예약 실행은 알림과 최근 실행 이력에 표시된다.
- [ ] `pr-review-reminder --doctor`가 keychain의 활성 `github.com` 계정과 로그인을
  표시하고, API timeout을 인증 실패로 잘못 안내하지 않는다.
- [ ] Claude와 Codex 각각 리뷰 생성, 취소, 10분 timeout 경로를 확인한다.
- [ ] 베이스+스킬 모드에서 여러 스킬 파일의 저장·재실행과 `{{SKILL}}` 합성을 확인한다.
- [ ] 선택한 스킬 파일을 이동·삭제하면 분석이 실행되지 않고 읽기 오류가 표시된다.
- [ ] 지침이 있는데 `{{SKILL}}`이 없는 템플릿은 분석 전에 명확한 오류를 표시한다.
- [ ] 게시 미리보기를 취소하면 GitHub 쓰기가 전혀 발생하지 않는다.
- [ ] head SHA가 바뀐 PR은 게시가 차단되고 재리뷰 안내가 표시된다.
- [ ] 존재하지 않는 라벨로 피드백 이슈를 만들면 생성 URL과 누락 라벨 경고가 남는다.

## 상세 화면과 접근성

- [ ] 리뷰/변경 내용/나란히 전환 시 중요한 컨텐츠가 화면 왼쪽 위에서 시작한다.
- [ ] Split/Unified diff의 긴 줄을 가로 스크롤할 수 있다.
- [ ] 파일 검색·파일 선택·이전/다음 변경 탐색이 올바른 줄로 이동한다.
- [ ] 인라인 코멘트의 파일:줄 링크가 변경 내용의 해당 side/line으로 이동한다.
- [ ] 첫 번째·중간·마지막 인라인 코멘트를 각각 편집·삭제해도 다른 본문이 바뀌지 않는다.
- [ ] 키보드만으로 메뉴, 설정, 상세, 게시 미리보기의 모든 동작에 접근한다.
- [ ] VoiceOver가 아이콘 버튼, 상태, 오류, 입력 필드를 의미 있는 순서로 읽는다.
- [ ] 한국어/English 변경 시 열려 있는 모든 창 제목과 본문이 즉시 갱신된다.

## 데이터와 종료

- [ ] 설정과 히스토리 저장 위치·크기·마지막 저장 상태가 실제 파일과 일치한다.
- [ ] 손상된 히스토리 fixture가 백업된 뒤 빈 목록으로 안전하게 복구된다.
- [ ] 리뷰/조회/업데이트 중 종료하면 확인 대화상자가 나타난다.
- [ ] 알림을 끄면 신규 PR, 리뷰 완료, 예약 실패 알림이 발송되지 않는다.

- [ ] README의 화면 자료가 이번 릴리스 UI와 일치한다.
